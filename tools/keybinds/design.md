# Пресет управления UniversIO

Исходные 185 зарегистрированных назначений сохранены в `stock.txt`. Они
взяты из `options.txt` тестового экземпляра UniversIO на Minecraft 1.19.2,
Forge 43.2.10 и Java 17. SHA-256 полного снимка:
`e272d9cf25dd1deca5382bc1ccc851fea2305d8a51ad5a2e7b12553356441bc2`.
Ревизия поставки для проверки `a4ecd8ce9f7013d2bda77b1fd869f846411af8b2`
добавила скрипт модели скина и файл владения. По сравнению с предыдущей
поставкой книг её JAR не изменились. SHA-256 всех JAR в текущем манифесте
закреплены в `source-jars.json`.

`layout.json` меняет только выбранные назначения. Первые 34 базовых
назначения Minecraft сохраняются. Отдельные действия модов получают
разные физические клавиши. Сортировка Backpack и Inventory Sorter доступна
раздельно, а настройки карты, брони и оружия больше не используют одну
клавишу. Быстрый выход и скрытие окна выключены во избежание случайного
прерывания игры. Прежние неназначенные действия остаются неназначенными.

Crafting Tweaks через Balm регистрирует сочетания в GUI. Семейство
сжатия сохраняет K, Ctrl+K и Shift+K. Пополнение использует стрелку вниз
и Ctrl+стрелку вниз. Для сжатия `ModKeyMappings.getCompressType` выбирает
один результат через `isActiveAndMatches`. В проверку конфликтов входят
совпадения основных физических клавиш и этих двух семейств. Левый Ctrl
сохраняется для бега, Ctrl в сочетаниях остаётся модификатором.
Колесо Inventory Sorter оставлено с авторскими кодами mouse.100/102.
`KeyHandler$ScreenEventHandler` обрабатывает клавиатуру, мышь и колесо.
В Squirt Gun открытие окна учитывает фактическое назначение Forge.

Проверка выполняется вне игры. Она охватывает зарегистрированные
назначения из сохранённого прогона, проверенные контексты и совпадения
физических клавиш. Непривязанные к `KeyMapping` перехватчики и потребление
ввода открытыми экранами не проверялись.

```text
python tools/keybinds/check_preset.py --write
python tools/keybinds/check_preset.py
```

`publish.yml` публикует изменение пресета как отдельный проверяемый архив,
сохраняет остальные строки публичного манифеста и обновляет его последним.
При новом наборе модов сначала снимите зарегистрированные назначения на
целевой платформе и пересмотрите раскладку.
