# UniversIO

Подготовка сборки 5.3 для LANMinecraft. [Авторский клиентский выпуск](https://www.curseforge.com/minecraft/modpacks/universio/files/5035806)

`tools/upstream-client-lock.json` фиксирует SHA256 и размер оригинального ZIP, ссылки на официальный источник, записи зависимостей и SHA256 файлов внутри авторских overrides. Minecraft и загрузчик взяты из оригинального манифеста. Java в `portable-pack.json` соответствует выбору текущего лаунчера для этой версии Minecraft и проверяется при запуске.

## Восстановление авторского клиента

Закреплённый авторский клиент CurseForge использует project ID 735681 и file ID 5035806.
Для подготовки текущего кандидата из корня LANMinecraft запустите:

```powershell
python -B tools/PackData/CurseForge/release_overlay.py stage --pack-source LocalSources/UniversIO --output $stage
```

`tools/overlay.json` сохраняет политику открытия мира через Steam. Для нового
авторского выпуска снимите отдельную квитанцию через `prepare.py --client-only`
и проверьте её из корня LANMinecraft:

```powershell
python -B LocalSources/UniversIO/tools/review_author_update.py --launcher-source . --candidate-lock $candidateLock
```

Проверка сверяет размер и SHA256 авторского `main_menu.txt`, затем вызывает
общую проверку рецепта и печатает предложенный `overlay.json`. Результат
не записывается в исходники автоматически. При изменении защищённого входа
пересмотрите рецепт и закрепите новые точные байты. После нативной проверки
сохраните полный `tools/upstream-lock.json` и выполните `release_overlay.py verify`
по готовому манифесту.

`tools/curseforge-fallbacks.json` закрепляет три обязательные зависимости с пустыми метаданными CurseForge. Project ID и file ID взяты из авторского `manifest.json`, имена проектов сверены по `modlist.html` того же экспорта. Полные файлы получены с официального CDN по точным file ID.

- Almost Unified `633823/4886620` совпал по SHA256 и CRC32 `d44e19d1` с `mods/almostunified-forge-1.19.2-0.7.2.jar` из авторского серверного архива 5.3. [Серверный архив UniversIO 5.3](https://www.curseforge.com/minecraft/modpacks/universio/files/5035809)
- Tiny Item Animations `808006/4331279` совпал побайтно с авторским выпуском Forge `C5JsLyaK` на Modrinth. Авторские заметки объясняют его отсутствие в серверном архиве. [Авторский выпуск Tiny Item Animations](https://modrinth.com/mod/tiny-item-animations/version/C5JsLyaK)
- Durability101 `325020/3829751` получен с официального CDN по ID и имени закреплённого файла. Размер 4 112 байт, SHA1 `4545850709df2cccc96d9c8540a8563f1d1c08b1`. Файл отсутствует в серверном архиве. [Официальный проект Durability101](https://www.curseforge.com/minecraft/mc-mods/durability101)

## Языки игровых книг

Справочник UniversIO и стартовые книги FTB Quests, Advanced Peripherals,
Hex Casting и Squirtgun используют язык клиента. По тому же правилу
отображается «Лексикон Ботании» из награды задания. Русская версия загружается
при входе в мир с языком `ru_ru`. После переключения языка в уже открытом
мире войдите в него заново, чтобы Patchouli 77 перечитал страницы. Для
остальных языков доступны исходные локализации модов и английский текст.

- Справочник UniversIO использует каталоги `en_us` и `ru_ru` Patchouli.
- Книга заданий использует подстановки FTB Quests 1902.5.7 в авторских SNBT
  и строки `kubejs/assets/universio_quests/lang`. Идентификаторы заданий,
  требования, награды и структура глав сохраняются.
- Страницы Advanced Peripherals и Squirtgun добавляются в их исходные JAR
  слоем ресурсов. Инструмент сверяет точные входные и выходные SHA256.
  Идентификаторы книг и байты исполняемых классов сохраняются.
- Русский ресурс Hex Casting дополняет перевод из оригинального JAR.
  Источники и лицензии указаны в [licenses](licenses).
- Русский ресурс Botania дополняет перевод «Лексикона Ботании» для версии 440.
  Отдельный файл с условиями и авторством лежит в каталоге `licenses`.

Исходники Advanced Peripherals взяты из [тега 1.19.2-0.7.29r](https://github.com/IntelligenceModding/AdvancedPeripherals/tree/1.19.2-0.7.29r).
Для Squirtgun [официальный файл 4256080](https://www.curseforge.com/minecraft/mc-mods/squirt-gun/files/4256080)
помечен GPLv2. [Соответствующий исходный код и файлы сборки](https://github.com/DirtEngineers/Squirtgun/tree/313f0879f0330e999d2474ed8bdeea1b577b13ba)
дополнены в этой ревизии исходниками переводов. [Публикация лицензии автором](https://github.com/DirtEngineers/Squirtgun/tree/0c182188cca02a1741e9e84105253465db857d39)
не меняла игровую логику относительно этого выпуска. Точное преобразование
JAR выполняет [инструмент подготовки LANMinecraft](https://github.com/MarkZamore/LANMinecraft/blob/cbff8c0458c73aad4f315548ed791986367f75ac/tools/PackData/CurseForge/prepare.py).

При обновлении авторского клиента или одного из этих модов проверьте тексты
и точные входные файлы в `tools/overlay.json`. Нативные пробы в `tools`
проверяют стартовые предметы, загруженные книги Patchouli и реальные
клиентские компоненты текста FTB Quests на английском и русском.

## Скин в главном меню

Клиентский скрипт KubeJS находит модель текущего игрока в авторской разметке
FancyMenu и передаёт ей текстуру локального профиля из Minecraft. Лаунчер
добавляет свой скин в тот же профиль, который использует сама игра. Скрипт
сохраняет позу, плащ, имя и остальную разметку меню. Если в профиле нет
текстуры, работает штатное поведение FancyMenu.

При обновлении `review_author_update.py` сверяет разметку главного меню, а
общий рецепт проверяет зафиксированные версии FancyMenu, KubeJS и Rhino.
При изменении этих входов проверьте собственный скин и оба варианта модели
рук в запущенном клиенте перед обновлением закреплённых значений.

Для проверки скрипта без игры запустите `tools/UniversioSkinProbe.java` через
Java 17 с Rhino и библиотеками Minecraft 1.19.2 из установленной сборки.
Укажите путь к скрипту первым аргументом. Проверка выполняется в настоящем
Rhino с его маппингами и подставными объектами экрана, клиента и FancyMenu.

```powershell
java -cp "$classPath" tools/UniversioSkinProbe.java kubejs/client_scripts/lanmc_menu_player_skin.js
```

В рабочем каталоге LANMinecraft есть отдельная нативная проверка без ввода с
клавиатуры и мыши. Из корня LANMinecraft запустите по очереди:

```powershell
$probe = 'LocalSources/UniversIO-fancymenu-skin-20261114/tools/universio_title_skin_fixture.py'
python -B $probe Plan
python -B $probe Control
python -B $probe Slim
python -B $probe Classic
```

`Plan` читает свежий опубликованный манифест, проверяет закреплённые версии и
показывает объём одной копии. Следующие команды используют существующий
изолированный стенд `guest-peer-remaining-20261114` и запускают по одному
клиенту Forge 43.2.10 через аргументы опубликованного лаунчера 500. Используются
его фактический JAR адаптера и ранее проверенные маппинги для 1.19.2. Байткод
хуков скина идентичен в двух ревизиях адаптера. Проверка
использует сгенерированный PNG, локальный сервер `127.0.0.1` и реестр скинов
для синтетического игрока. Элемент главного меню проверяется в потоке игры.
Ожидаются активная модель рук и три точных пикселя загруженной OpenGL-текстуры.
`Control` проверяет, что авторское меню без добавленного скрипта не принимает
синтетический скин автоматически. Сохраняются компактные результаты, копия
игры удаляется. Сценарий не входит в поставку сборки.

На опубликованной сборке `38bc16b` с лаунчером 500 первый вариант на
`ClientEvents.paintScreen` оставил модель Стива. В поставляемой версии KubeJS
события `paintScreen` и `tick` ждут локального игрока в мире. Исправленный
скрипт подписывается на экранное событие Forge, доступное в главном меню.
Нативная проверка увидела модель Slim, загрузку синтетического PNG и три
точных пикселя лица на OpenGL-текстуре. Клиент завершился с кодом 0.

## Кнопка жалоб в меню паузы

FancyMenu распознаёт кнопку «Открыть для сети» и размещает её справа от
настроек. После публикации встроенного сервера Minecraft использует в этом
слоте кнопку с ключом `menu.playerReporting`. Клиентский скрипт UniversIO
перемещает её в свободный слот, если исходные координаты перекрывают другую
кнопку. Слот определяется по координатам «Статистики» и «Настройки…» после
разметки FancyMenu. Обработчик нажатия и остальные кнопки не меняются.
При изменении авторской разметки `review_author_update.py` требует пересмотра.

`tools/UniversioPauseProbe.java` проверяет перенос, занятый слот,
неопубликованный мир и изменение размера на Rhino из состава сборки.
Запустите Java 17 с Rhino, клиентскими JAR Minecraft и Forge 43.2.10
и их зависимостями в `$classPath`:

```powershell
java -cp "$classPath" tools/UniversioPauseProbe.java kubejs/client_scripts/lanmc_pause_reports_layout.js
```

## Уведомление об обновлении ProjectE

При входе в мир ProjectE PE1.0.1B выводит в чат версию и ссылку на загрузку.
Клиентский скрипт UniversIO отключает подписчик ProjectE, который выводит эти
сообщения. Проверка версий Forge остаётся включённой.

`tools/overlay.json` закрепляет скрипт и файл ProjectE 3955047.
`review_author_update.py` сохраняет скрипт при обновлении авторского архива.
Если автор заменит ProjectE, проверка потребует сверить обработчик в новом JAR
и обновить запись зависимости перед публикацией.
